# e05: Build and release (backlog slice S5)

Goal: a tagged release can be turned into an iOS Xcode project with one command, the version comes from the release
tag, CI proves the export works on every pull request, and nothing secret is ever in the repository.
Scope in: device project settings (landscape, icon, offline), iOS export preset without signing data, export and
version scripts, an export hygiene check in preflight, a macOS export job in CI that uploads the Xcode project as an artifact.
Scope out (needs the owner's Apple account): signing, provisioning, App Store Connect upload, store listing and
screenshots, TestFlight. The export stops at an unsigned Xcode project.

## Stories (WSJF order)

| Story | Title | Why here |
|---|---|---|
| e05s01 | Device project settings | Without landscape and an icon the export is wrong |
| e05s02 | iOS export preset and script | The export itself, no secrets |
| e05s03 | Version ladder | The tag is the only source of the version |
| e05s04 | CI export job | Proves the export on every pull request |

## Decisions

- The bundle id is `com.danielvm.quiqui.cleanup` (a placeholder the owner can change in one place, the preset). Team id,
  provisioning profile and certificates are left empty in the repository and given at export time through the environment
  (`QQ_APPLE_TEAM_ID`), never committed (AGENTS.md "Never").
- `config/version` in `project.godot` stays `0.0.0`. The release tag is the version. `scripts/export_ios.sh` writes the
  tag's version into a temporary copy of the presets, so the repository never carries a stale number.
- Version ladder: `v0.N.0` per finished slice while the game is unreleased; the first store build is `v1.0.0`, tagged by
  hand with a `feat!` or a `Release-As` note after the owner decides. big-release computes the rest from commit types.
- The CI export job is macOS (free on a public repository), exports the Xcode project only, and uploads it as a workflow artifact.
  It does not sign and does not attach to the release (the release job runs in parallel; attaching is for a later slice).
- Placeholder icon: QuiQui on a pink square, generated by `scripts/make_icon.py`. Final icon art is a people task.

## Acceptance (epic)

- `bash scripts/export_ios.sh` produces an Xcode project under `build/ios` from a clean checkout with the export templates installed.
- `bash scripts/check_export.sh` fails on a planted team id, provisioning profile, network permission or missing icon.
- CI has an export job that passes on this branch.
- Preflight green, `bash scripts/trace_stories.sh --strict` passes, only two `.tscn` files exist.
