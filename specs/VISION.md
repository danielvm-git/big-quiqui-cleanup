# Vision

## What it is

QuiQui Cleanup is a tidy-up game for children aged 4 to 7. A messy house has five rooms. The child wipes dust,
puts toys away and opens curtains, and each room goes from a mess to sparkling. The child hears a family voice,
sees a picture and gets an answer to every touch.

## The promise

"I fixed the mess." Every step is small and always works: show a hint, the child makes a gesture, the game checks it,
QuiQui reacts, a reward appears. A wrong drop returns the item. Nothing is lost.

## Charter

| Rule | Meaning |
|---|---|
| Offline | No network call of any kind |
| No ads, no telemetry, no store | Nothing leaves the device |
| No reading | Every prompt is a picture plus a voice or a sound |
| No punishment | No lives, no game over, no timer that ends a step |
| Family voice | Recorded by the family, Brazilian Portuguese first. Other languages are folders, not code |
| Touch first | iPad 4:3 and 16:9 phones and tablets, with no letterbox |

## Not goals

Accounts, cloud save, subscriptions, a shop, multiplayer, anything that needs reading.

## Success for the first release

A child cleans the living room with no adult help and asks to play again (slice S1).
The finished game is five rooms, each cleaned in two or three steps, plus a title screen, a house map and a reward.

## Why this game first

It is the simplest of the nine QuiQui games: seven templates, all from the first build wave, no new engine piece.
It builds the shared core that the other eight games reuse. See `specs/product/LINE_PLAN.html`.
